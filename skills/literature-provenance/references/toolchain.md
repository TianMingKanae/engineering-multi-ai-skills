# Literature evidence tool contracts

DOI retrieval uses the DOI resolver with `Accept: application/vnd.citationstyles.csl+json` and `application/x-bibtex`; HTTPS redirects are limited to known registration-service hosts. See [Crossref content negotiation](https://www.crossref.org/documentation/retrieve-metadata/content-negotiation/) and [DOI resolution/URI encoding](https://www.doi.org/the-identifier/resources/factsheets/doi-resolution-documentation). The tool fails on unsupported agencies/redirects instead of falling back to a publisher page or model-generated citation. Unicode/punctuation normalization is allowed for comparison; ambiguous markup or changed title identity requires manual review. Registry metadata can still be wrong; verify consequential citations against authorized full text.

```shell
python skills/literature-provenance/scripts/doi.py <doi> --expected-title "Exact independently checked title" --policy venue-policy.json --out approved-reference
python skills/literature-provenance/scripts/locate_quote.py local-source.pdf --quote "A short exact passage."
```

Venue policy schema: `{"venues":[{"name":"Example Journal","issn":["local-synthetic-id"],"type":"article-journal","tier":"selected-journal"}],"allowed_tiers":["selected-journal"]}`. Use real registry identifiers only in your local reviewed policy, with its provenance/version recorded. A conference uses `paper-conference` and a locally selected tier. Posted content/preprints are always labeled preprint before policy lookup. Unknown venues are unclassified; neither is approved unless explicitly listed in allowed_tiers. "Top" or "flagship" is a curated local assessment, not something a title/model can establish. A venue gate is a scope filter, not a validity or prestige guarantee. Exit 2 means blocked and creates no approved reference directory; title/DOI failures exit 1.

The quote tool accepts UTF-8 text (form feeds delimit pages) or local PDFs with optional pypdf. PDF page indices are physical one-based indices; PDF page-label metadata is reported separately and may differ from numbers printed on the page. A text export's page index is not a physical PDF page claim unless an independently preserved page map establishes it. Headings are heuristic and may be null. Preserve the original source, extracted text/version and source/page hashes. Scans require separate authorized OCR and visual review. Equations, ligatures, columns and line wraps may extract incorrectly; a not-found result must not be replaced with invented wording. Copyright/context limits still apply to the actual source and sharing purpose; 40 units is a tool ceiling, not blanket redistribution permission.

Core scheduling, SQLite evaluation, DOI networking and text quote location use Python's standard library. PDF location needs pypdf; HDF5, classic MAT and Parquet adapters need h5py, scipy and pyarrow respectively. See requirements-optional.txt at the toolkit root. Install only the adapters you need in a project environment. The MAT example supports classic scalar structures, not every MAT variant. Never use pickle/object deserialization as an artifact shortcut. Resource limits and library security updates belong to the execution host.

For an authorized local corpus, run `python skills/literature-provenance/scripts/archive_corpus.py --corpus local-corpus --policy rights.json --out corpus-manifest.json`. Policy shape: `{"files":{"source.txt":{"source_id":"local-1","version":"v1","access_basis":"authorized-local-copy","permitted_nodes":["review-node"],"redistribution":"approved recipients only"}}}`. Every PDF/text file needs a rights record. The manifest stores relative filenames and source hashes, not machine paths. Rights declarations still require independent entitlement review. Automated acquisition must remain on the entitled node; transport to other nodes must honor the declared limits.
